# Hyon Technologies - Next Generation IT Solutions

Hyon Technologies is a modern tech startup redefining how businesses access cutting-edge software and AI solutions. We design scalable, high-performance systems that are accessible to startups, growing businesses, and forward-thinking teams.

## Overview

This repository contains the source code for the official Hyon Technologies landing page and web application. Built with Next.js, React, and modern web technologies, it showcases our services, technology stack, and client portfolio.

### Features
- **Modern UI/UX**: Built using Tailwind CSS, Framer Motion, and custom 3D WebGL components via Three.js.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **Search Engine Optimized**: Developed with semantic HTML5 structuring, correct heading hierarchies, and built-in JSON-LD schemas.
- **Performance Focused**: Includes visibility-gated rendering for heavy GPU tasks to ensure smooth 60fps scrolling.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (React)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Graphics**: Three.js integration
- **Icons**: [Lucide React](https://lucide.dev/)

## Getting Started

First, run the development server:

```bash
npm install
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
